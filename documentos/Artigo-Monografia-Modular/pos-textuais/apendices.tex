	\chapter{Questionário aplicado}\label{apendice:questionario}

	Os apêndices reúnem material elaborado pelo autor que complementa o texto, como questionários, roteiros de entrevista, dados brutos ou demonstrações. Exemplo de questionário:

	\begin{alineas}
		\item Qual é o seu curso?
		\item Você já escreveu algum trabalho em \LaTeX?
		\item Qual editor de texto você usa com mais frequência?
	\end{alineas}
